Программа поддерживает следующие опции командной строки:

Опция	Описание
--help	Показать справочное сообщение и выйти.
-d, --directories	Директории для сканирования (по умолчанию: текущая директория .).
-e, --exclude	Директории, которые следует исключить из сканирования.
-l, --level	Уровень сканирования (0 — только указанная директория, по умолчанию: 0).
-m, --min-size	Минимальный размер файла для сканирования (по умолчанию: 1 байт).
-k, --masks	Маски файлов для сканирования (например, *.txt, *.cpp).
-b, --block-size	Размер блока для чтения файлов (по умолчанию: 5 байт).
-a, --algorithm	Алгоритм хэширования (crc32 или md5, по умолчанию: crc32).
